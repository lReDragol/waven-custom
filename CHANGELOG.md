# Изменения

## 2.0.0

- Новый редактор PySide6: список элементов, холст и инспектор свойств.
- Масштаб, изменение размера мышью, выравнивание, готовые палитры, отмена и повтор действий.
- Установщик Windows x64 на русском с регистрацией обработчиков аудио.
- Портативная ZIP-сборка с данными рядом с EXE, без обязательной установки.
- Выбор плеера для MP3 через системные параметры Windows с подтверждением пользователя.
- Репозиторий содержит исходники и инструкции сборки; локальные проверочные скрипты не публикуются.

### Возможности плеера

- Новое окно музыки: очередь отдельно от сохранённых плейлистов; основные действия всегда на виду.
- Названия, исполнители, альбомы и длительность из тегов. Чтение в фоне, без изменения аудиофайлов.
- Поиск по метаданным, перенос выбранных песен в другой плейлист, подсветка текущего трека.
- Контрастная мятная кнопка PLAY/PAUSE с увеличенной тёмной надписью. Защита от нечитаемых цветов темы.
- 14 цветных аудиореактивных эффектов и отключение визуализации. Выбор по миниатюрам, сохранение режима.
- Волны, цветные ленты, спектры с пиковыми отметками, лепестки, орбита и двухканальные осциллографы.
- Проверки тегов, поиска, редактирования очереди, оформления, визуализаторов и собранного EXE.
